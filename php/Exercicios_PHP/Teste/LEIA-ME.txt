Cadastro de Usuários

Olá pessoal, esse cadastro de usuários é show.
É totalmente em Português.
Tem a opção dos usuaríos se cadastrarem.
Você pode adicionar usuários, deletar usuários
e também gerenciar usuários.
Muito bom para quem quer registringir o acesso de pessoas
não autorizadas a determinada página.
------------------------------------
ARQUIVOS CONTIDOS ----------------
altclientes.php - Altera dados de usuários ou clientes

cadclientes.php - Cadastra usuários ou clientes

conecta.php - Conecta ao Banco de Dados

excluirclientes.php - Exclui clientes ou usuários

gerclientes.php Gerencia clientes e usuários

index.php - Página inicial, onde pede a senha e se não estiver cadastrado a pessoa leva para a área de cadastro.

ver_sessao.php - Verifica cadastros

tables.txt - Cria a tabelas necessárias

tabelas.sql - Se preferir usar esse arquivo para criar as tabelas fica sua escolha, mais eu aconselho que você tenha o MySQL-FONT
-------------------------------------------------------------------------------------------------------------------------------
-------------------------------------------------------------------------------------------------------------------------------
COMO INSTALAR
Antes de tudo cria um Banco dew Dados.
Abra o arquivo conecta.php e preencha com os dados do seu Mysql de acordo com o Banco de Dados

Agora você deve criar as tabelas. Parece ser um bicho de sete kbeças, mais não chega a ser.
Você tem 2 opções.
Manualmente, usando o arquivo TABLES.TXT execute esse arquivo dento da sua base, uma dica.
 Copier e cole esse arquivo dentro da sua base, usando o PHPMYADMIN.


A segunda opção é Você usar o table.sql - Juntamente com o MySQL-FONT ou o PHPMYADMIN executando dentro da sua base.

Feito isso está pronto para ser usado..
É um script muito bom. Se não fosse bom, eu não indicaria ele a vocês.
